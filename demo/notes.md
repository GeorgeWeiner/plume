# Plume demo notes

A **feather-light** terminal IDE prototype.

## Things to try

- Press `Ctrl+P` and type `fib` to jump to the Python file
- Press `Ctrl+Shift+F` and search for `plume`
- Press `Ctrl+K` then `Ctrl+T` to switch themes
- Select a word and press `F2` to rename it in this file

> Editing philosophy: the editor should weigh nothing
> and get out of your way.
